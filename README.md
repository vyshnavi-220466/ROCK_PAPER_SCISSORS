# Rock Paper Scissors Game

An interactive Rock Paper Scissors game developed using HTML, CSS, and JavaScript where users can play against the computer in real time.

## Features

- User vs Computer gameplay
- Random computer choice generation
- Instant game result display
- Win, Lose, and Draw detection
- Score tracking system
- Interactive user interface
- Responsive design for different devices
- Fast and smooth gameplay experience

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- Game Interface
- User Choice Selection
- Computer Choice Generator
- Score Tracking System
- Result Display Section

## Purpose

This project was developed to strengthen JavaScript programming skills by implementing game logic, random number generation, event handling, and DOM manipulation.

## Learning Outcomes

- JavaScript Logic Building
- Event Handling
- DOM Manipulation
- Conditional Statements
- Random Number Generation
- Interactive User Interface Design
- Responsive Web Design

## How to Play

1. Select Rock, Paper, or Scissors.
2. The computer automatically makes its choice.
3. The result is displayed instantly.
4. Scores are updated based on the outcome.
5. Continue playing to improve your score.
